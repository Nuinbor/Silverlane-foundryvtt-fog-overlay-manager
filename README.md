# Silverlane Fog Overlay Manager

Кастомный модуль для **Foundry VTT v14**: индивидуальные изображения вместо
неисследованного тумана войны для каждого игрока и этажа сцены. Без обязательных
зависимостей и привязки к игровой системе. Интерфейс на русском и английском.

## Возможности

- Таблица «игроки × этажи»: путь к изображению, штатный браузер файлов, включение,
  удаление назначения и кнопка **«Подогнать»** в каждой ячейке.
- Перетаскивание изображения и восемь маркеров растяжения. Ширина и высота меняются
  независимо; доступны точные X/Y, размеры в пикселях, поворот и размер в футах
  или других единицах сетки сцены.
- Размер сцены, карта этажа, стены и токены не изменяются.
- Исследованные области остаются открытыми после ухода персонажа и перезахода.
  Сброс тумана мастером снова их закрывает. Используется штатная память Foundry.
- Выбор игроков, которым разрешено отображение каждого тайла.
- Настройки синхронизируются штатными обновлениями сцены/тайла; отдельный сервер
  и скрипты на стороне игроков не нужны.

## Установка

### По ссылке в Foundry (рекомендуется)

В меню **Add-on Modules → Install Module** вставьте в поле **Manifest URL**:

```text
https://github.com/Nuinbor/Silverlane-foundryvtt-fog-overlay-manager/releases/latest/download/module.json
```

Нажмите **Install**, затем включите модуль в управлении модулями мира.
Нужен опубликованный релиз с `module.json` и `module.zip`; простой push исходников
не создаёт эти файлы автоматически. Следующие релизы публикуются workflow по тегу.
Не используйте адрес GitHub с `/blob/main/module.json`: это HTML-страница,
а не manifest для установщика.

### Из собранного архива

1. Скачайте [module.zip из последнего релиза](https://github.com/Nuinbor/Silverlane-foundryvtt-fog-overlay-manager/releases/latest/download/module.zip).
   Также доступны промежуточные сборки в
   [Actions → Test and package](https://github.com/Nuinbor/Silverlane-foundryvtt-fog-overlay-manager/actions/workflows/ci.yml).
   Если скачиваете артефакт Actions, сначала распакуйте внешний ZIP: внутри будет
   установочный `module.zip`. Для артефактов Actions может требоваться вход в GitHub.
2. Остановите мир Foundry. Создайте каталог
   `Data/modules/silverlane-fog-overlay-manager/` в пользовательских данных Foundry.
3. Распакуйте содержимое установочного `module.zip` в этот каталог. Файл
   `module.json` должен лежать непосредственно в нём, не во вложенной папке.
4. Перезапустите Foundry и включите **Silverlane Fog Overlay Manager** в управлении
   модулями мира. После включения перезагрузите окна мастера и игроков.

Локальная сборка из этого репозитория:

```sh
npm ci
npm run check
npm test
npm run build
```

Архив появится в `dist/module.zip`. Для **использования** модуля Node/npm не нужны —
они нужны только разработчику для сборки и тестов.

## Использование

1. В настройках сцены включите **Token Vision** и сохранение исследования тумана.
   Для раздельного исследования каждым игроком выберите индивидуальный режим.
2. Настройте встроенные этажи в разделе **Levels** сцены.
3. Откройте менеджер одним из способов:

   - кнопка с картой в инструментах токенов слева;
   - правый клик по сцене → «Управление изображениями тумана»;
   - настройки модуля → «Управление изображениями тумана».

4. Выберите сцену в верхнем списке. В ячейке «игрок × этаж» выберите изображение
   через папку или введите путь/HTTPS URL. Путь сохраняется при завершении изменения
   поля. Разные ячейки сохраняются независимо; одну ячейку не редактируйте
   одновременно в двух окнах мастера — последнее сохранение победит.
5. Нажмите **«Подогнать»**. Мастер переключится на нужную сцену и этаж; появится
   временное изображение для совмещения с картой.
6. Перемещайте изображение, тяните боковые/угловые маркеры или вводите размеры.
   X/Y — левый верхний угол неповёрнутого изображения в координатах холста с учётом
   полей сцены; поворот выполняется вокруг центра.
7. Нажмите **«Сохранить подгонку»**. Изменения применятся у игроков; краткая
   перезагрузка холста для обновления текстуры ожидаема. Обновлять страницу не нужно.

Прозрачность в редакторе изменяет **только предпросмотр мастера**. Игроки его не
видят. Это не режим просмотра тумана глазами игрока. Escape отменяет текущий жест;
«Отмена» закрывает редактор без сохранения. Смена сцены/этажа также закрывает его
без сохранения.

### Пример: сцена 100 × 100 футов, второй этаж 75 × 60

При сетке `100 px = 5 ft` размеры сцены — `2000 × 2000 px`. Для второго этажа
задайте ширину `1500 px` и высоту `1200 px`, затем переместите картинку до
совпадения со схемой. Другому игроку можно назначить другой план и другую подгонку
того же этажа. Вокруг подогнанного изображения остаётся обычный неисследованный
туман — картинка не повторяется плиткой.

### Видимость тайлов

В настройках тайла найдите **Silverlane · Видимость для игроков**. Включите
«Показывать тайл только выбранным игрокам», отметьте пользователей и сохраните
**обычной кнопкой окна настройки тайла**.

- Ограничение выключено: стандартные правила Foundry.
- Ограничение включено, никто не выбран: тайл не виден ни одному игроку.
- Мастер сохраняет обычный доступ к тайлу.
- Разрешение игроку не отменяет стандартное скрытие, этажность и другие правила.
  Ограничения тайла для света и погоды остаются общими.
- Это **фильтр отображения, не защита файлов/данных**. Документы сцены и URL могут
  быть доступны клиенту; не используйте функцию для секретных файлов, которые
  игрок категорически не должен иметь возможности скачать.

## Foundry v14 и Levels

В v14 многоэтажные сцены встроены в Foundry. Автор Levels перевёл версию 7.x
преимущественно в инструмент миграции:
[официальная документация Levels](https://wiki.theripper93.com/levels).

Модуль использует **встроенные документы Level v14**, в том числе сцены,
перенесённые из Levels. Устанавливать Levels необязательно. Перенос старых сцен
автоматически не запускается. Сначала сделайте резервную копию и мигрируйте старую
сцену. Движок Levels из Foundry v12/v13 не поддерживается.

При **общем исследовании тумана** изображения индивидуальны, но открытые области
общие — модуль не меняет режим сцены. Если сохранение исследования или Token Vision
отключены, замена тумана не применяется; менеджер показывает предупреждение.
У мастера остаётся обычный вид карты.

Файлы должны быть доступны браузерам игроков. Предпочтительны локальные ресурсы
Foundry (PNG/JPG/WebP). Внешние URL требуют корректных CORS-заголовков и HTTPS,
если Foundry работает по HTTPS. Видео не предлагаются в браузере изображений.
При недоступном файле применяется стандартный туман этажа.

## Для разработчика

Node.js 22+; все зависимости используются только при разработке.

```sh
npm ci
npx playwright install chromium
npm run check
npm test
npm run test:browser
npm run build
```

Проверяются manifest, синтаксис, импорты, шаблоны и паритет переводов. Браузерные
тесты используют настоящий PIXI 7 и Chromium. Они **не заменяют запуск Foundry**:
процедура проверки с двумя игроками — [docs/TESTING.md](docs/TESTING.md). Исходники
и лицензия Foundry не включены.

API для консоли мастера или макроса Script:

```js
game.modules.get("silverlane-fog-overlay-manager").api.openManager();
// Также принимает документ сцены или её ID:
game.modules.get("silverlane-fog-overlay-manager").api.openManager(canvas.scene.id);
```

### Выпуск обновления

Обновите версии в `module.json` и `package.json`, путь `download` в manifest и
`CHANGELOG.md`, выполните проверки и push. Затем опубликуйте тег `vX.Y.Z`,
совпадающий с версией manifest. Workflow `Release module` создаст GitHub Release
с `module.zip`, `module.json` и контрольными суммами. До отдельной приёмки в
Foundry устанавливайте модуль в копию тестового мира.
