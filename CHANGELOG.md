# Changelog

## 0.1.0 — 2026-11-13

- GM-only matrix: players as rows, native Foundry v14 Levels as columns.
- Foundry image browser, enable/clear controls per assignment.
- Canvas drag, eight resize handles, numeric X/Y/width/height/rotation, fit and reset.
- Native saved fog: explored areas do not become covered when a token moves away.
- Optional per-player tile display restrictions in Tile Configuration.
- English/Russian UI, no runtime dependencies or game-system assumptions.
- Automated Node/DOM and Chromium/PIXI tests, deterministic ZIP, CI and tag-based releases.

Initial version: live multi-client Foundry acceptance testing is still required; see `docs/TESTING.md`.
